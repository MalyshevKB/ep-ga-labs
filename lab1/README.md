# ЛР №1 — вещественный ГА, вариант 16 («изогнутая сигара»)

**Выполнил:** Малышев Кирилл Борисович, группа Б24-527

Группа Б24-527 (Q=2), N=15, Y=26: V = 1 + ((17·15 + 7·2 + 26) mod 20) = 16; d = 5 + (16 mod 6) = 9.

## Установка и запуск
```bash
pip install -r requirements.txt
python run_experiments.py --runs 30 --seed0 1000 --budget 100000
python make_flowchart.py      # блок-схема -> results/flowchart.png
```
Параметры: `--runs` число независимых запусков (≥20), `--seed0` seed первого запуска (запуск k использует seed0+k),
`--budget` лимит вычислений f. Результат полностью воспроизводим при тех же seed.
Проверено на Python 3.14, numpy 2.5, pandas 3.0, matplotlib 3.11, scipy 1.18; серия из 6 конфигураций × 30 запусков
выполняется примерно за 30 секунд.

## Файлы
- `ga.py` — целевая функция, операторы (турнир, ранговая селекция, BLX-α, гауссова мутация, отражение от границ, элитизм), ГА и случайный поиск.
- `run_experiments.py` — серия запусков, статистика, графики.
- `results/configs.json` — параметры всех конфигураций; `results/runs.csv` — все запуски; `results/summary.csv` — статистика;
  `results/mannwhitney.csv` — p-значения теста Манна—Уитни (база против остальных);
  `results/*.png` — графики.
- `report.md` — отчёт.
